Use Case диаграмма информационной системы складского учета

Три роли системы и функции, доступные каждой роли.

Тип: Use Case
Система: складской учет
Акторы: гость, сотрудник, админ

Информационная система складского учета

Гость
неавторизованный пользователь
расширение прав
Сотрудник
работа со складом
расширение прав
Админ
управление системой

Функции гостя

  • просмотр открытого каталога товаров;
  • переход к форме авторизации.

Функции сотрудника

  • просмотр остатков на складе;
  • оформление приемки и списания товаров;
  • формирование рабочих отчетов.

Функции администратора

  • управление учетными записями пользователей;
  • настройка справочников системы;
  • просмотр журнала действий.
