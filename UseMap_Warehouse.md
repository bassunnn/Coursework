# UseMap информационной системы "Складской учет материалов"

## Назначение

UseMap выполнена в формате MVP-карты: сверху расположены разделы системы, слева роли пользователей, а внутри сетки показаны функции, доступные каждой роли.

Готовые файлы:

- `UseMap_Warehouse.svg`
- `UseMap_Warehouse.png`

## Роли

| Роль | Цвет | Назначение |
| --- | --- | --- |
| Новый сотрудник | Красный | Регистрация и вход в систему. |
| Сотрудник склада | Зеленый | Основная работа со складским учетом. |
| Не входит в MVP | Серый | Возможности, которые можно добавить позже. |

## Разделы карты

| Раздел | Функции |
| --- | --- |
| Регистрация | Регистрация нового сотрудника по коду приглашения. |
| Справочники | Поиск материалов, фильтрация, карточка материала, поставщики. |
| Приход | Добавление прихода, список приходных записей, поиск прихода, расчет суммы. |
| Отчеты | Сводка склада, поставщики материала, количество поставщиков, поиск по адресу банка. |
| Авт. / Выход | Вход по email, выход из аккаунта, темная тема, хранение токена. |

## Примечание

Зеленые блоки отражают функциональность сотрудника склада, красные блоки относятся к новому сотруднику до входа в систему. Серые блоки показывают возможности, которые можно добавить позже и которые не входят в MVP.
